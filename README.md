# לוח מודעות בית כנסת – פרויקט אנדרואיד

האפליקציה היא מעטפת WebView מסך מלא (Landscape, מסך תמיד דולק) שמריצה את `app/src/main/assets/index.html` מקומית, בלי דפדפן ובלי סרגלים.

## בניית ה-APK – אפשרות א': GitHub (בלי להתקין כלום)
1. צרו ריפוזיטורי חדש ב-GitHub והעלו אליו את כל התוכן של התיקייה הזו (כולל `.github`).
2. עברו ללשונית **Actions** ← **Build APK** ← **Run workflow**.
3. בסיום (כ-3–5 דקות) הורידו את `ShulBoard-APK` מה-Artifacts, פתחו את ה-zip ותקבלו `app-debug.apk`.
4. העבירו לטאבלט/טלפון והתקינו (יש לאשר "התקנה ממקורות לא ידועים").

## אפשרות ב': Android Studio
`File → Open` על התיקייה הזו, המתינו לסנכרון, ואז `Build → Build APK(s)`.
הקובץ ייווצר ב-`app/build/outputs/apk/debug/app-debug.apk`.

## מה שונה ב-HTML לעומת המקור
- הנתונים נשמרים בזיכרון המכשיר (localStorage) ולא נמחקים בסגירת האפליקציה.
- ספריית ה-Excel מצורפת מקומית (לא נטענת מהרשת).
- ייצוא רשימות נשמר לתיקיית ההורדות במכשיר.
- כפתור "חזור" באנדרואיד מחזיר מהקרוסלה לתפריט.

## הערות
- Hebcal (פרשה, תאריך עברי) דורש חיבור לאינטרנט.
- ייבוא קבצי PDF עדיין לא ממומש בקוד המקורי (רק Excel).
- כפתור "ייצא PDF" מייצא בפועל קובץ טקסט (כך היה במקור).
- גרסת debug מספיקה להתקנה ישירה; לפרסום ב-Google Play יש לחתום גרסת release.
- אנדרואיד 10 ומעלה.
